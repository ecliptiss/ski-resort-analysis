# Ski Resort Analysis

This small project, originally for competition but became an independent project, looks at how climate change has affected the viability of ski resorts. It mainly focuses on climate data such as temperature and snowfall and how they have changed from 2010 to 2025. This data is used to suggest future analyses for both a more comprehensive measure of impacts and methods to minimize them in the future.

## Includes:
- Excel file with data analysis (statistics, graphs, some inferential tests)
- Documentation portfolio explaining our process in greater detail
- Data used for analysis
